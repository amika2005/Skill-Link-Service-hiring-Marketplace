# Skill Link - Service Hiring Marketplace

🚀 **Android app connecting users with skilled local service providers.**

## Features
- Browse & book local services with transparent pricing
- Real-time chat & integrated payments
- Worker profiles with ratings & reviews
- Job scheduling & earnings tracking

## Tech Stack
- **Frontend**: Android (Java) + Material Design
- **Backend**: Firebase Firestore
- **Auth**: Firebase Authentication
- **Payment**: PayHere Integration

## Quick Start
1. Clone the repository
2. Add your `google-services.json` to `app/` directory
3. Add Google Maps API key to `strings.xml`
4. Build: `./gradlew build && ./gradlew installDebug`

## Security Notes
- This project contains no real API keys or credentials
- All sensitive data has been removed for public repository safety
- Use your own Firebase and API keys for development
